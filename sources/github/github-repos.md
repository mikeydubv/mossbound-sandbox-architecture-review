# Open-Source GitHub Research Catalog

> Curated for Claude from the Dubs Game Studios / Misfitz / Mossbound research trail.

## How to use this catalog

Use the links as research entry points. Prefer official documentation and current repository code over remembered behavior. Before adapting code, inspect the repository license, dependency versions, and the exact commit or release being used.

## Core Three.js and game foundations

- [mrdoob/three.js](https://github.com/mrdoob/three.js) — Core Three.js engine, WebGPU, TSL, editor commands, selection, and history patterns.
- [pmndrs/react-three-fiber](https://github.com/pmndrs/react-three-fiber) — React renderer for Three.js.
- [pmndrs/drei](https://github.com/pmndrs/drei) — R3F helpers for controls, loaders, cameras, environments, and interaction.
- [pmndrs/racing-game](https://github.com/pmndrs/racing-game) — Open racing-game architecture, drift effects, dust, and trails.
- [pmndrs/postprocessing](https://github.com/pmndrs/postprocessing) — Bloom, SSAO, chromatic aberration, motion blur, glitch, and color effects.
- [pmndrs/react-three-rapier](https://github.com/pmndrs/react-three-rapier) — Rapier physics integration for R3F.
- [pmndrs/use-gesture](https://github.com/pmndrs/use-gesture) — Pointer and touch gesture handling.
- [pmndrs/leva](https://github.com/pmndrs/leva) — Runtime debug controls.
- [pmndrs/gltfjsx](https://github.com/pmndrs/gltfjsx) — GLTF/GLB to React component pipeline.
- [pmndrs/uikit](https://github.com/pmndrs/uikit) — WebGL-rendered UI components.
- [pmndrs/miniplex](https://github.com/pmndrs/miniplex) — Entity Component System patterns.
- [pmndrs/valtio](https://github.com/pmndrs/valtio) — Proxy-based state management.
- [pmndrs/jotai](https://github.com/pmndrs/jotai) — Atomic state management.
- [pmndrs/react-spring](https://github.com/pmndrs/react-spring) — Spring-based animation.
- [pmndrs/cannon-es](https://github.com/pmndrs/cannon-es) — Lightweight JavaScript physics.
