This folder collects the open-source repositories and projects used as references during Dubs Game Studios, Misfitz, Mossbound, and Three.js research.

These are source links and notes only. The repositories are not vendored into this project.

- **Primary catalog:** [github-repos.md](github-repos.md)
- **Purpose:** give Claude a compact, navigable research map for graphics, terrain, editors, gameplay, animation, multiplayer, VFX, and AI tooling.
- **Important:** verify each repository's current license and API before copying or adapting code. Some entries are projects or organizations rather than a single repository because they were part of the research trail.
